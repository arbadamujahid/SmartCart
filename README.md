# Product Recommendation System

A multi-platform product recommendation system.

## Data Cleaning & Preprocessing

This part of the project focuses on cleaning and standardizing product datasets collected from multiple e-commerce platforms.

### Platforms

* Amazon
* Flipkart
* Myntra
* Nykaa

### Product Categories

* Fashion
* Beauty
* Laptops
* Mobiles
* Shoes

### Cleaning Tasks

The following preprocessing tasks were performed:

* Removed missing product IDs
* Removed duplicate product IDs
* Cleaned and standardized product information
* Separated datasets by platform and category
* Checked cleaned datasets for consistency
* Standardized datasets into a common format
* Prepared the cleaned datasets for further processing

### Scripts

The data-cleaning scripts are available in the `scripts/` directory.

They include scripts for:

* Amazon dataset cleaning
* Flipkart dataset cleaning
* Myntra dataset cleaning
* Nykaa dataset cleaning
* Duplicate ID checking
* Cleaned-data validation
* Dataset standardization
* Master dataset preparation

### Cleaned Dataset

The cleaned datasets are available as a compressed file:

```text
data/cleaned_datasets.zip
```

The ZIP file contains the cleaned datasets generated during the preprocessing stage.
